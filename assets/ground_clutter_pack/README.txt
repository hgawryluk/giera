Important:
These are 2D generated renders, not actual 3D meshes. The alpha versions are suitable for fast prototyping with QuadMesh/Sprite3D/billboards. For final-quality rocks, pebbles and twigs, replace them later with real low-poly/photogrammetry 3D meshes. Grass and weeds can remain billboard/alpha-card based if desired.
